# API de gestión de hoteles

API REST para la gestión de información hotelera, desarrollada con Java, Spring Boot y Maven. El proyecto utiliza Spring Data JPA para persistencia, MySQL como base de datos y Springdoc para documentar la API.

## Tecnologías

- Java 17.
- Spring Boot 3.1.
- Spring Web y Spring Data JPA.
- MySQL.
- Springdoc OpenAPI.

## Requisitos

- JDK 17.
- Maven.
- Una instancia de MySQL con la conexión configurada en la aplicación.

## Ejecutar

```bash
mvn spring-boot:run
```

Consulta los controladores del proyecto para conocer los recursos y operaciones disponibles. La configuración de la base de datos debe adaptarse al entorno local; no publiques contraseñas ni claves.
